# Changelog — Release Candidate 1.1

- Added three distinct weapon profiles and weapon switching (keys 1/2/3 or Switch button).
- Added ADS/aim zoom (right mouse button or Aim button).
- Added three-step stance cycle: standing, crouching, prone.
- Adjusted enemy visual detection and incoming fire probability for low-profile stances.
- Kept magazine/reserve ammunition per weapon when switching.
- Corrected mission restart to consistently initialize the primary rifle and ammunition.
- Improved contextual objective/extraction distance feedback.
- Replaced the Android WebView entry point with the self-contained offline runtime.
- Re-ran JavaScript syntax and mission/asset validators.

Not represented as completed: Unity compile, Android APK build, hardware testing, full 3D rendering/animation, or exhaustive playtest.
